# prueba-figma-v0

Base inicial del proyecto para trabajar con v0 y desplegar en Vercel.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- ESLint
- Vercel-ready

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Build de producción

```bash
npm run build
npm start
```

## Deploy en Vercel

Importar este repositorio desde Vercel. El framework será detectado automáticamente como Next.js y no requiere configuración adicional para el primer deploy.
